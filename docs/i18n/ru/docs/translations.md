# Переводы документации

Выберите язык в основном README. В каждой языковой папке находятся полные README, спецификация комплектующих, инструкции по печати и сборке, характеристики, руководство по моделям, правила участия, лицензирование, правила работы с репозиторием и сведения об авторах. Ссылки между этими документами сохраняют выбранный язык.

Английские оригиналы остаются на прежних путях. Переводы находятся в `docs/i18n/<language>/` и повторяют структуру исходных папок. CAD, файлы симуляции, изображения, видео и исходный PDF-буклет общие. Текст внутри иллюстраций остаётся частью исходных рисунков; руководство по сборке содержит переведённые инструкции, таблицы деталей, предупреждение о питании и условные обозначения. Юридические тексты лицензий и машиночитаемая конфигурация общие и не переводятся.

<a id="translation-status"></a>
## Статус переводов

Первые переводы подготовлены с помощью ИИ и локальной модели перевода, затем проверены на полноту структуры, ссылки и сохранение технических значений. Проверка носителями языка ещё не проведена. При неоднозначности сверяйтесь с английским оригиналом; ошибки сообщайте через GitHub issue, указав язык, документ и предложение. Успешный CI не подтверждает языковую или аппаратную корректность.

<a id="contribute-a-translation"></a>
## Как внести перевод

1. При изменении инструкций или технических данных сначала обновите английский оригинал.
2. Обновите соответствующий документ в каждой языковой папке. Сохраните таблицы, все шаги, предупреждения, номера деталей, числа, команды и внешние URL.
3. Ссылки на документы должны сохранять язык. Для общих файлов используйте относительные пути. Сохраните явные английские ID якорей для ссылок на разделы.
4. После проверки затронутых переводов зафиксируйте версию оригинала командой `python .github/scripts/check_translations.py --record-reviewed --locale ru --source docs/bom.md`. Команда только записывает версию: она не переводит и не проверяет текст.
5. Запустите `python .github/scripts/check_translations.py` и `pre-commit run --all-files`. Отправьте изменения через PR и укажите, какие языки проверены.

При добавлении исходного Markdown-документа внесите его путь в манифест переводов и создайте соответствующий файл во всех языковых папках. CI обнаруживает неучтённые оригиналы, изменённые хеши, отсутствующие переводы, сломанные ссылки и якоря, изменённые номера деталей, потерянные таблицы и разделы.

<a id="repository-conventions"></a>
## Правила репозитория

В корневом README есть ссылки на языки: GitHub не выбирает перевод автоматически для каждого читателя. Каждый перевод ссылается на такой же документ на остальных языках и на английский оригинал. Папки используют теги BCP 47. Десять языков выбраны для международной аудитории, а не по рейтингу количества носителей. Для сопровождения исходным остаётся английский.
