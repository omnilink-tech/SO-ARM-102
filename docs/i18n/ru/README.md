Здесь описаны все существующие документы репозитория. По ссылкам доступны полные английские оригиналы с таблицами, иллюстрациями и PDF-буклетом. Эти описания не являются полными переводами или инструкцией по сборке.

| Документ | Содержание |
|---|---|
| [`README.md`](../../../README.md) | Обзор проекта, этапы сборки, конфигурации, известные проблемы, команда и связанные проекты. |
| [`docs/bom.md`](../../../docs/bom.md) | Комплектующие для одной ведущей и одной ведомой руки, варианты сервоприводов, ссылки закупки и допущения расчёта стоимости. |
| [`docs/printing.md`](../../../docs/printing.md) | Материалы, проекты слайсера, настройки печати, количество деталей, оценки расхода пластика и времени. |
| [`docs/assembly-guide.md`](../../../docs/assembly-guide.md) | Иллюстрированные этапы сборки, идентификаторы сервоприводов, замечания по проводке и первый запуск. |

| [`CONTRIBUTING.md`](../../../CONTRIBUTING.md) | Как сообщать о проблемах, изменять детали, проверять посадку и лицензировать вклад. |
