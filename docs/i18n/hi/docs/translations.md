# दस्तावेज़ीकरण अनुवाद

मुख्य README में अपनी भाषा चुनें. प्रत्येक भाषा फ़ोल्डर में पूर्ण README, बिल ऑफ़ मटेरियल्स, प्रिंटिंग निर्देश, एसेम्बलिंग गाइड, स्पेसिफिकेशन, मॉडल गाइड, योगदान दिशानिर्देश, लाइसेंसिंग गाइड, भंडार मार्गदर्शन तथा श्रेय सूचनाएँ हैं. इन दस्तावेज़ों के बीच लिंक्स चुनी गई भाषा में रहते हैं.

अंग्रेज़ी स्रोत दस्तावेज़ अपने मौजूदा पथ पर रहते हैं. अनुवाद `docs/i18n/<language>/` में है और स्रोत फ़ोल्डर संरचना को प्रतिबिंबित करता है. CAD, सिमुलेशन फ़ाइलें, छवियाँ, वीडियो तथा मूल PDF पुस्तिका साझा की जाती है. पाठ तथा लेबल जो मौजूदा चित्रों में अंतर्निर्मित होते हैं वे खींचे जाने के रूप में बने रहते हैं; एसेम्बलिंग गाइड में अनुवाद निर्देश, भाग तालिकाएँ, वोल्टेज चेतावनी तथा चित्र कथा शामिल होती है. मूल कानूनी लाइसेंस पाठ तथा मशीन- पढ़ने योग्य विन्यास साझा किए जाते हैं, अनुवाद नहीं.

<a id="translation-status"></a>
## अनुवाद स्थिति

पहले अनुवाद AI सहायता और एक स्थानीय अनुवाद मॉडल के साथ तैयार किया गया था, फिर संरचनात्मक पूर्णता, लिंक और संरक्षित तकनीकी मूल्यों के लिए जाँचा. वे मूल वक्ताओं द्वारा समीक्षा नहीं की गई है. अस्पष्टता को हल करने के लिए अंग्रेजी स्रोत का उपयोग करें और GitHub मुद्दे के माध्यम से अनुवाद समस्याओं की रिपोर्ट करें, भाषा, दस्तावेज़ और प्रभावित वाक्य सहित. पारित CI जांच भाषाई या हार्डवेयर सटीकता प्रमाणित नहीं करता है.

<a id="contribute-a-translation"></a>
## अनुवाद में योगदान करें

1. निर्देश या तकनीकी डाटा बदलने पर पहले अंग्रेजी स्रोत संपादित करें.
2. प्रत्येक भाषा फ़ोल्डर में मिलता- जुलता दस्तावेज़ अद्यतन करें. तालिका, सभी चरण, चेतावनी, भाग पहचानकर्ता, संख्यात्मक मूल्य, कमांड तथा बाहरी यूआरएल को संरक्षित रखें.
3. स्थानीय दस्तावेज़ लिंक को उसी भाषा में रखें. साझा संपत्ति के लिए सापेक्षिक पथ का उपयोग करके लिंक करें. आंतरिक खण्ड लिंक द्वारा प्रयोग किए जाने वाले स्पष्ट अंग्रेजी एंकर आईडी को बनाए रखें.
4. प्रभावित अनुवादों की समीक्षा के बाद, `python .github/scripts/check_translations.py --record-reviewed --locale ru --source docs/bom.md` के साथ स्रोत संस्करण रिकॉर्ड करें. यह कमांड केवल संस्करण रिकॉर्ड करता है; यह पाठ का अनुवाद या समीक्षा नहीं करता है.
5. `python .github/scripts/check_translations.py` और `pre-commit run --all-files` चलाएँ. परिवर्तनों को एक पुल् अनुरोध में जमा करें तथा बताएं कि कौन सी भाषाओं की समीक्षा की गई है.

जब एक स्रोत मार्कडाउन दस्तावेज़ जोड़ें, अनुवाद मैनिफ़ेस्ट में इसका पथ जोड़ें तथा प्रत्येक भाषा फ़ोल्डर में संबंधित फ़ाइल प्रदान करें. सीआई जाँच सूचीबद्ध नहीं किए गए स्रोत दस्तावेज़ों, बदली हुई स्रोत हैश, गुम अनुवाद, टूटी स्थानीय लिंक, गुम एंकर, बदली तकनीकी पहचानकर्ता, खोई तालिकाएँ तथा गुम खण्डों का पता लगाती है.

<a id="repository-conventions"></a>
## रेपोसिटरी कन्वेंशन

रूट README भाषा लिंक प्रदान करता है क्योंकि GitHub स्वचालित रूप से प्रत्येक पाठक के लिए एक अनुवादित README चुनता नहीं है. हर अनुवादित दस्तावेज़ सभी अन्य भाषाओं में समतुल्य दस्तावेज़ और उसके अंग्रेजी स्रोत के साथ लिंक करता है. भाषा फ़ोल्डर BCP 47 टैग का उपयोग करते हैं. दस भाषाएँ व्यावहारिक अंतर्राष्ट्रीय दर्शकों की चयन, स्पीकर गणना द्वारा रैंकिंग नहीं है. अंग्रेजी रखरखाव के लिए स्रोत भाषा बनी रहती है.
