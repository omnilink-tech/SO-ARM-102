# ترجمة الوثائق

اختار لغتك في README الرئيسي. كل مجلد لغة يحتوي على README كامل، قائمة المواد، تعليمات الطباعة، دليل التجميع، المواصفات، الدليل النموذجي، المبادئ التوجيهية للمساهمة، دليل الترخيص، توجيه المستودع وإشعارات النسب. تظل الروابط بين هذه الوثائق باللغة المختارة.

تبقى وثائق المصدر الإنجليزية في مساراتها الحالية. الترجمات هي في `docs/i18n/<language>/` وتعكس بنية مجلد المصدر. CAD، ملفات المحاكاة، الصور، الفيديو والكتيب الأصلي PDF يتم تقاسمها. النصوص والعلامات المضمنة في الرسوم التوضيحية الموجودة تظل كما رسمت؛ دليل التجميع يتضمن التعليمات المترجمة، جداول الأجزاء، تحذير التيار الكهربائي وتفسير الرسوم التوضيحية. نصوص الترخيص القانوني الأصلي والتهيئة المقروءة آلياً يتم تقاسمها، لا ترجمتها.

<a id="translation-status"></a>
## حالة الترجمة التحريرية

تم إعداد الترجمات الأولى بمساعدة الذكاء الاصطناعي ونموذج للترجمة المحلية، ثم تم التحقق من اكتمال البنية والروابط والقيم التقنية المحفوظة. لم يتم استعراضها من قبل المتحدثين الأصليين. استخدم المصدر الإنجليزي لحل الغموض والإبلاغ عن مشاكل الترجمة من خلال مسألة GitHub، بما في ذلك اللغة والوثيقة والجملة المتضررة. لا يشهد فحص CI الناجح على صحة اللغوية أو المعدات.

<a id="contribute-a-translation"></a>
## المساهمة بترجمة

1. تحرير المصدر الإنجليزي أولاً عند تغيير التعليمات أو البيانات التقنية.
2. تحديث الوثيقة المطابقة في مجلد كل لغة، والمحافظة على الجداول وجميع الخطوات والتحذيرات ومحددات الأجزاء والقيم الرقمية والأوامر وعناوين الإنترنت الخارجية.
3. 2-1-3-4- الاحتفاظ بوصلات الوثائق المحلية باللغة ذاتها، والربط بالأصول المشتركة باستخدام المسارات النسبية، والمحافظة على الهويات الإنكليزية الصريحة المستخدمة في وصلات الأقسام الداخلية.
4. بعد مراجعة الترجمات المتأثرة، سجّل نسخ المصدر مع `python .github/scripts/check_translations.py --record-reviewed --locale ru --source docs/bom.md`. هذا الأمر يسجل النسخ فقط؛ وهو لا يترجم أو يراجع النص.
5. تشغيل `python .github/scripts/check_translations.py` و`pre-commit run --all-files`. تقديم التغييرات في طلب سحب وذكر اللغات التي تم استعراضها.

عند إضافة وثيقة Markdown المصدر، أضف مسارها إلى بيان الترجمة وقدم الملف المقابل في كل مجلد لغة. ويكتشف فحص CI وثائق المصدر غير المدرجة، ومتغيرات المصدر المحذوفة، والترجمات المفقودة، والروابط المحلية المكسورة، والمراسي المفقودة، ومتغيرات التعريف التقنية، والجداول المفقودة والأقسام المفقودة.

<a id="repository-conventions"></a>
## اتفاقيات الإيداع

يوفر الجذر README روابط اللغة لأن GitHub لا يختار تلقائيا ترجمة README لكل قارئ. كل وثيقة مترجمة تربط إلى الوثيقة المكافئة في كل لغة أخرى وإلى مصدرها الإنجليزية. ملفات اللغات تستخدم BCP 47 علامات. اللغات العشر هي اختيار عملي للجمهور الدولي، وليس ترتيبا حسب عدد المتكلمين. تظل اللغة الإنجليزية لغة المصدر للصيانة.

- [GitHub README وروابط ذات صلة](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)
- [مسار عمل ترجمة وثائق GitHub](https://github.com/github/docs/blob/main/src/languages/README.md)
